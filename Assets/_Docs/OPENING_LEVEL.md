# Opening Level Brief — Bastion Zero Forest

## Setting
Lush, tree-covered region of Bastion Zero. Ancient trees, soft lighting, occasional broken structures or signs of prior presence. The full fire wave and monster have not arrived. Atmosphere is melancholic but still explorable and beautiful.

## Level Flow
1. Safe starting clearing
2. Basic platforming section introducing movement
3. Mid-level puzzle (pressure plate + door or equivalent)
4. More vertical or challenging platforms with hidden collectibles
5. Clear exit trigger or door

## Required Features
- Polished 2D platformer controls
- Cinemachine follow camera with look-ahead and smooth damping
- 3–5 collectibles (some obvious, some slightly hidden)
- One light environmental puzzle
- Level exit that can later connect to the next region
- Approximate playtime: 2–4 minutes

## Visual Notes
- Side-view 2D
- Dominant greens and natural tones
- Tilemap-driven level geometry
- Subtle environmental storytelling only (no text or cutscenes required)

## Acceptance Criteria
- Scene loads and is playable from start to exit
- Movement feels responsive (coyote time + jump buffering present)
- Collectibles can be picked up
- Puzzle can be solved
- Exit trigger fires a clear completion event or log
